# P0 Lite Approved Baseline

Status: Approved
Approval date: 2026-09-12

## Approved product direction

- Begin with one inter-purok pilot.
- Preserve a generic architecture for inter-barangay and inter-town expansion.
- Build a mobile-first public website, organizer dashboard, and scorer interface.
- Use an API-first Laravel backend for the React web client and a future Expo application.

## Approved pilot defaults

- One open division.
- Maximum registered roster: **20 players per team**.
- Single round robin.
- Top four qualify for single-game semifinals.
- Semifinal pairing: 1st vs 4th and 2nd vs 3rd.
- Single championship game.
- Four 10-minute quarters.
- Five-minute overtime.
- One official scorer device per game.
- Organizer finalizes results.
- Initial live tracking: team score, game clock, quarter, team fouls, and timeouts.
- Public viewers do not require accounts.
- Livestreams use authorized external Facebook or YouTube links.

## Deferred decisions and features

- Exact standing points and tiebreaker order remain configurable and must be confirmed before standings implementation.
- Player points and advanced statistics are deferred until basic live scoring is reliable.
- Native mobile application is deferred.
- Advanced/double-elimination brackets are deferred.
- Public organizer onboarding, payments, comments, and self-hosted video are deferred.
